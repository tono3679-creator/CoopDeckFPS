# ART_BIBLE — 配色と見た目の決まり

2026-11-08 にユーザーが「夕方の空中遺跡」を選択。コード上の唯一の出どころは `Assets/_Game/Scripts/Core/Palette.cs`。
色を足すときは、まずここと `Palette` に足してから使う（マテリアル・エフェクト・UI に色の直書きをしない）。

## 1. スタイル

柔らかい 2 階調の陰影と細い輪郭線のトゥーン調。**地形は落ち着いた中間色、敵・属性・エフェクトだけが鮮やかに光る**
（`PROJECT_OVERVIEW.md` §3「カラフルで視認性の高いトゥーン調」）。

## 3. 光

西日の暖色キーライト、空からの藍色の照り返し。

## 4. エフェクトの決まり（火球で確立、他のスキルにも適用する）

- 色はパレットからだけ取る（粒子の開始色は白＝マテリアルのランプの色をそのまま出す）。
- **炎の本体（炎の殻・炎の粒・軌跡・衝撃波）は半透明合成**。加算合成は白熱した中心と火花だけ。加算の赤は青空の上でピンク〜紫に
  にじみ、重なると白飛びするため。
- 縁は半透明にせずくっきり切る（濃い赤の半透明は空の青と混ざって紫になる）。消えるときは透明にせず、ノイズで削れていく（Dissolve）。
- 光るのは高温部だけ（`_CoreBoost`）。手元や画面いっぱいの発光はしない。
- 3D の形（メッシュ）と流れるノイズで立体感を出し、平たい丸い粒を並べない。
