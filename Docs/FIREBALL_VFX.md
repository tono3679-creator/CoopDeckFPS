# FIREBALL_VFX — 火球スキルの演出（2026-11-08）

キツネ（火）の基本スキル「火球」の発射・飛翔・着弾・爆発・余韻の演出と、ゲームへの組み込み。今後のスキル VFX の品質基準。
配色は `ART_BIBLE.md`、カードの数値は `CARD_SYSTEM.md` §12.1。

## 1. 作り方の方針（ユーザー決定）

- **Particle System（Shuriken）＋ Shader Graph ＋ メッシュ**で作る。VFX Graph 17.5.0 は Editor に同梱だが未導入で、公開 API ではグラフの
  ノード追加・接続ができない（`VFXViewController` が internal）ため、確実に作れない手段は使わない（ユーザー確認済み）。
- Particle System・マテリアル・Prefab・メッシュ・Shader Graph はすべて Editor スクリプトで生成する（`FireballVfxFactory`、ブートストラップで再生成）。
  メッシュは Blender ではなく C# で生成した（Blender を使う必要がなかった）。
- 既存のダメージ・炎上・属性コンボの処理は重複実装しない。命中時は `SkillCaster.Resolve` をそのまま呼ぶ。

## 2. ゲーム側の流れ

```
DeckController.UseSlot（Q/E/F・LB/RB/Y）
  └ SkillCaster.CastCard(火球) ─ projectile.IsProjectile
       ├ 0.00 s  castFx を左手のひらに出す（一人称の手＝ViewModel レイヤー、手に追従）
       ├ クイック詠唱モーション（SkillMotionRules → QuickCast：0.15 s で手のひらが前に出る）
       ├ 0.12 s  発射：照準の線上を 45 m/s の球（半径 0.2 m）で毎フレーム SphereCastNonAlloc
       │          見た目（projectileFx）は手のひらから出て 6 m で照準の線に合流（ConvergeDistance）
       │          一人称の手は画角の違う ViewModel カメラが描くので、ワールドカメラの同じ画面位置に変換して出す
       ├ 命中（敵・地形）→ Resolve：直撃 45・半径 2.5 m に 20・炎上 毎秒 6×3 秒・属性ヒット（→ コンボ）
       │          areaFx（爆発）を命中点に。地形は面の向き、敵は撃った方向へ向ける。impactFx（炎が絡みつく）は敵に追従
       └ 射程 60 m で何にも当たらなければ、ダメージなしで溶けるように消える
炎上中（StatusEffectsModel.HasDamageOverTime(火)）は ElementAuraPresenter が敵の体に小さな炎を出し、炎上の終了で消す
```

- 味方・自分・倒れた敵はすり抜ける。物理の照会は共有バッファで GC なし。
- 最初の 1 発で引っかからないよう、`DeckController.Start` が初期デッキの飛翔弾カードの演出をプールに事前生成（`SkillCaster.Prewarm`）。
- ネットワーク化の接続点：`SkillCaster.StepProjectiles(dt)` は public（固定ティックで回せる）。弾の判定は照準の線上なので、ホストで同じ結果になる。

## 3. 演出の構成（`Assets/_Game/Prefabs/Skills/Fireball/`）

| フェーズ | Prefab | 内容 |
|---|---|---|
| A 発射 0.00〜0.12 s | `FX_Fireball_Cast` | 手のひらの白黄色のコアが膨らみ、橙の炎が回転しながら巻き付き、火花が集まる → 発射の瞬間に外へ散る。手元が光りすぎないよう小さく、発光を抑える |
| B 飛翔 | `FX_Fireball_Projectile` | 白熱コア（メッシュ・脈動）、炎の殻 2 層（彗星形メッシュ・頂点を流れるノイズで揺らし、進行方向の逆へ流れて渦を巻く・後ろから燃え尽きる）、炎の軌跡（Trail 2 本）、置き去りの炎と火の粉（ワールド空間・距離あたりの放出なので高速でも途切れない）、発射の噴き出し、点光源（高のみ）。発射直後は小さく出て 0.12 s で本来の大きさに、置き去りの炎は 0.07 s（約 3 m）から（目の前で炎が立ち上らない） |
| C 命中 0.00〜0.40 s | `FX_Fireball_Explosion` | 白黄色の閃光 → 立体の火球（凹凸メッシュ）が膨らむ → 凹凸メッシュの炎の塊 9 個が飛び出し、減速しながら巻き上がって冷え、削れて消える → 炎の舌、衝撃波リング（中品質以上で二重）、火花。地形では面に沿って広がり（壁なら壁に沿う）、敵では撃った方向を向く縦のリング（小さめ、床に刺さらない） |
| C 敵への命中 | `FX_Fireball_TargetFlare` | 胸元から炎が体に沿ってらせん状に巻き上がる（敵に追従、0.6 s）。直撃とスプラッシュで 2 回出さない |
| D 余韻 0.40〜1.20 s | （爆発の続き） | 漂う火の粉、赤く光る燃焼片（メッシュ、地面で跳ねる）、灰色の薄い煙、地形では焦げ跡（キャラクターに当たったときは出さない） |
| D 炎上 | `FX_Burning` | 炎上（火の継続ダメージ）の間、体の表面から炎の舌・火の粉・少しの煙。炎上の終了で放出を止め、0.6 s で自然に消える |

## 4. シェーダー（Shader Graph、`Assets/_Game/Art/VFX/Fireball/Shaders/`）

`ShaderGraphWriter` が URP Unlit の .shadergraph を書き出し、計算は `FireballVfx.hlsl` の Custom Function（キツネのシェーダーと同じ構成）。
6 グラフとも同じプロパティ一式を持つ（HLSL を丸ごと各グラフに含めるため）。テクスチャなし、値ノイズ 2〜3 オクターブのみ。

| グラフ | 合成 | 用途 |
|---|---|---|
| `SG_FX_FireCore` | 加算 | 白熱コア（中心ほど白く、縁は橙、内部の渦と脈動）、燃焼片（冷えていく、光る割れ目） |
| `SG_FX_FlameVolume` | 半透明 | 炎の殻・爆発の炎の塊：頂点を流れるノイズで変形、渦、進行方向の逆へ流れる、炎の舌ごとに縁が赤く内側が黄色、年齢・`_Dissolve` で削れて消える |
| `SG_FX_FireParticle` | 半透明 | 炎の舌（先が上を向く形を揺らす）、軌跡（後ろへ流れる炎） |
| `SG_FX_FireGlow` | 加算 | 火花・火の粉・軌跡の芯・閃光 |
| `SG_FX_Smoke` | 半透明 | 煙（若いうちは炎の照り返し）、焦げ跡（残り火が消えていく） |
| `SG_FX_Shockwave` | 半透明 | リング：外寄りの細い帯をノイズで途切れさせ、年齢で削る |

- 温度（0〜1）を火の 4 色ランプで色にし、軽く階調化（`_Bands`）してキャラクターのトゥーン調にそろえる。白く光るのは高温部だけ（`_CoreBoost`）。
- 粒子は頂点ストリーム（UV・`StableRandom.x`・`AgePercent` → TEXCOORD0）で粒ごとの乱数と年齢をシェーダーへ渡す。
- カメラの目の前では炎・煙を薄くする（`_NearFade`）：近距離の爆発で視界を長く塞がない。
- URP の自動の描画順が「不透明」になってしまうため、マテリアルは描画順を手動（`_QueueControl` 1、キュー 3000）にしている。

## 7. パッシブで拡張するときの接続点（今回は実装していない）

| パッシブ | どこを変えるか |
|---|---|
| 巨大化 | `ProjectileSpec.visualScale`（見た目は `FireballProjectileFx` が全層を拡大）と `radius`（当たり） |
| 爆発範囲拡大 | カードの範囲ダメージの半径。爆発は `IRadiusFx.SetRadius` で炎の塊・リング・広がりが大きくなる（2.5 m 基準） |
| 3 方向分裂・追加発射 | `ProjectileSpec` に本数・角度を足し、`SkillCaster.Launch` で方向を変えて複数の `Flight` を作る（判定・演出はそのまま） |
| 追尾 | `Flight` に目標を持たせ、`StepProjectiles` で方向を回す（見た目は `Fly` の向きに従う） |
| 着弾地点に炎を設置 | 新しい効果種別（地面のダメージ床）を `SkillEffectSpec` に追加し、`Resolve` の中で設置（演出は別 Prefab） |
| レジェンダリーの見た目 | 別の `projectileFx`/`areaFx` Prefab を差し替えるだけ（生成ツールに色・層違いを追加） |

## 8. 残っていること

- 人の手でのプレイ確認（手触り・弾速・発射の 0.12 秒の遅れ・明るさ）。
- 効果音はまだない（今回の依頼範囲外）。発射・飛翔・爆発の音が入ると爽快感が大きく上がる。
- 火球以外のスキル・コンボのエフェクトは従来のまま（同じ作り方で作り直せる）。
- 三人称（他プレイヤーから見た）発射位置は体の左手（`FoxBodyAnimator.CastOrigin`）を使う設計だが、オンラインは Phase 6 のため未確認。
