# LIGHTNING_VFX — スタイライズした雷撃エフェクト

2026-11-08 ユーザー指示：「細い幾何学ラインに見えやすく、気持ちよさが足りない」雷を、太く読みやすいスタイライズした雷に作り直す。
方向性は「Gunfire Reborn のような太く気持ちよく読める雷」だけを参考にし、見た目やアセットは真似ていない（`PROJECT_OVERVIEW.md` のオリジナリティ規則）。
最初の適用先はサンダーホップの帯電連射（`THUNDERHOP_SMG.md`）。部品は共通なので、スキル「連鎖雷撃」やコンボの電撃にも使える。

同日の 2 回目の調整（動画で確認したうえでのユーザー指示「色と大きさを直す」）：発光の量ではなく、明るい背景で白く飛んで色が出ないこと、一人称で雷が小さく短いことが原因だった。合成を加算からアルファに変え、白い芯を細くしてシアンの帯で太く見せ、7.5 m の高さから落とし、3 回（連鎖先は 2 回）光る再点滅を入れた。

同日の 3 回目（ユーザー指示「発動時に『ドン、バチッ』と二段で弾ける派手な演出に」、基準は `Lightning_Fixed.mp4` の 7.6 秒付近の一人称）：左の敵が爆ぜ → 横に太い電撃が飛び → 右の敵がもう一度爆ぜる、が等速で読めるように、表示だけに時間差を付けた（§1.1）。再点滅はやめ、縦ボルトは約 0.1 秒で引く。

## 1. 構成

### 1.1 時間の流れ（表示だけ。ダメージ・対象選定・属性処理は放電のフレームで確定済み）

`HitscanWeapon.ReleaseChargeBurst` が放電のフレームで初撃と連鎖先のダメージ・属性ヒットを済ませてから `ChargeBurstTriggered` を出す。`WeaponFx` はそれを受けて、Chain（雷）のときだけ次の順に見せる（Splash＝IGNIS-27 は今までどおり全部同時）。時間は `WeaponFx` の `DischargeTiming`（初期値）で調整する。

| 時刻（放電から） | 表示 |
|---|---|
| 0 ms（同じフレーム） | 縦ボルトが接点に届き、接点に白い星形閃光・破片・火花。初撃の敵が強さ 0.5 で光る。発動者のカメラキック、破裂音 |
| 20〜220 ms | 床の衝撃波が広がって消える |
| 〜45 ms | 白いピーク |
| 〜100 ms | 縦ボルトが上から薄くなって消える。以後は火花と残留アークだけ |
| 75 ms（`chainDelay`） | 連鎖先への横アークが走り始める |
| 110 ms（＋`chainTravel` 35 ms） | 先端が連鎖先に届く：二発目の閃光・破片・床リング、連鎖先の敵が強さ 0.45 で光る、電気音 |
| さらに先の連鎖先 | 前の到達から `hopGap` 30 ms 後に次の横アーク |

- 連鎖先の位置は放電のフレームの値（報告のリストは使い回されるのでコピー）。表示までの間に敵が動けば一緒にずらし、**表示前に消えていたら最後の位置**で見せる（例外なし）。
- 放電は武器ごとの `ChargeBurstTriggered` を自分の `WeaponFx` が 1 回だけ再生する。2 人が同時に放電してもそれぞれ 1 回ずつ。ネットワーク同期は未実装（Phase 2.5 未着手）なので、通信版ではこのイベントを 1 放電 1 回だけ各クライアントへ送り、各自の `WeaponFx` で同じ時間差を付ける想定。

## 2. シェーダー（Shader Graph）

`Art/VFX/Lightning/Shaders/LightningVfx.hlsl` を Custom Function（File）で読むグラフ 2 つを `LightningVfxFactory` が書き出す（火球と同じ方式、`ShaderGraphWriter`）。どちらも**アルファ合成**、テクスチャ不要（値ノイズの計算だけ）。

**加算をやめた理由**：加算のシアンは明るい空や床の上では背景に足されて白く飛ぶだけで、発光を 1.7 倍にしても色は濃くならなかった（比較動画 `Lightning_GlowBoost.mp4`）。アルファ合成で帯が背景を覆うようにすると、背景の明るさに関係なくシアンが出る。芯とシアンの帯は 1 を超える HDR なので、Bloom で光るのは変わらない。

| グラフ | 用途 | 内容 |
|---|---|---|
| `SG_FX_LightningBolt` | ボルト・枝・残留アーク（Line Renderer、UV の x＝長さ方向、y＝幅方向） | 中心からの距離で芯（`_CoreWidth` の内側、`_CoreColor`×`_CoreBoost`）と帯（不透明度 `exp(-d²·_GlowFalloff)`×`_HaloOpacity`、帯の端で 0）。帯の色は芯の近くがシアン（`_GlowColor`）、外側ほど空色（`_EdgeColor`）。長さ方向に逆向きに流れる 2 層ノイズ（UV スクロール `_FlowSpeed`）で芯の太さと帯が脈打ち、明るいパルスが根元から先へ走る（`_PulseCount`・`_PulseSpeed`）。両端は柔らかく消える |
| `SG_FX_LightningFlash` | 命中の粒子（UV＋StableRandom.x＋AgePercent） | `_Mode` 0＝星形フラッシュ（丸い白熱の中心＋ノイズで長さが揃わない `_Rays` 本のトゲ）、1＝衝撃リング（年齢で半径が広がり細くなる帯、ちらつき）、2＝柔らかい光（中心シアン・外側空色の半透明、`_HaloOpacity`） |

マテリアル（`Art/VFX/Lightning/Materials`）：

| | 芯の明るさ | 芯の幅 | シアン | 帯の広がり（`_GlowFalloff`、小さいほど太い） | 帯の不透明度 |
|---|---|---|---|---|---|
| Bolt | 3.2 倍 | 0.11 | 1.2 倍 | 1.5 | 0.9 |
| Branch | 2.6 倍 | 0.15 | 1.1 倍 | 1.8 | 0.85 |
| Residual | 2.6 倍 | 0.17 | 1.1 倍 | 2.2 | 0.85 |
| Flash | 4 倍 | — | 1.4 倍 | 10 | 1 |
| Ring | 2.5 倍 | — | 1.5 倍 | 4 | 1 |
| Glow | — | — | 1.2 倍 | 3 | 0.45 |

Spark は既存の加算シェーダー。色は芯 `#F4FDFF`、シアン `#5ADCF4`、外側の空色 `#1E8FE6`。

**Bloom と色の兼ね合い**：`VP_Sandbox` は Bloom（しきい値 1.0）とトーンマップ（Neutral）。芯（3 倍前後）は Bloom で白くにじむ。シアンの帯を 1.5 倍以上にするとトーンマップで白っぽくなり、芯と区別できなかったので 1.2 倍に抑えた。芯を 4.5 倍にすると白いにじみが帯の色を消したので 3.2 倍にした。濃い紺の縁取りも試したが、青い空の上では見えなかった。

## 3. 近距離で画面を覆わない工夫

- メインボルトは真上から落とす（銃口からだと照準の前を横切る）。カメラから 7 m より近いボルトは距離に応じて細くなる（最小 45%）。
- 命中の粒子は画面サイズの上限つき（閃光 22%、光 30%、床リング 60%）。閃光の白い中心は胴幅の半分強で、外へ突き抜けるのは細いトゲだけなので、最大発光時でも敵の輪郭が追える。命中エフェクトは撃った側へ少し手前に出す（表面 0.25 m、連鎖先は体の中心から 0.5 m）ので敵にめり込まない。命中の柔らかい光は半透明の青で、敵を隠さない。
- 白く飛ぶのは芯の細い線だけ。シアンの帯は 1.2 倍に抑えている。

## 4. 品質（ROG Ally X 対応）

`PerformanceSettings.Vfx`（F4・`-vfx`、Ally X の既定は中）で分ける。

| | 高 | 中（Ally X 既定） | 低 |
|---|---|---|---|
| 枝（初弾 / 連鎖先） | 4 / 2 | 2 / 1 | 0 / 0 |
| 残留アーク | 3 本 | 2 本 | 1 本 |
| 床の衝撃波 | あり | あり | なし |
| 点光 | あり | なし | なし |
| 破片 8〜12・火花 10 | 全部 | 全部 | 全部（命中は密度で減らさない：粒は 1 回 25 前後） |
| メインボルト・閃光・横アーク・時間差・キック・音 | あり | あり | あり（読みやすさのため常に出す） |

描画するのは Line Renderer 最大 5 本（ボルト）＋3 本（残留）と粒子 3 種＋火花で、同時に出るのは雷撃 1 回あたりボルト 2 本・命中 2 か所程度。

## 5. 確認

- EditMode `LightningVfxTests`：ジグザグ（端点・振れ幅・同じシードで同じ形・描き直しで形を保つ・折れの 6〜9 割が左右交互）、品質ごとの枝と残留アークの数、時間差（連鎖の横アークは 65〜85 ms 後、到達は開始＋移動時間、3 体目は 2 体目の到達のあと）、縦ボルトが 80〜120 ms で消えること、2 つのグラフがアルファ合成、芯・シアン・空色の関係、雷を落とす高さ 6 m 以上、命中の Prefab（床リングは水平で 150〜220 ms、閃光のピーク 35〜55 ms、破片 8〜12、二発目は初撃の 70%、音があり連鎖先は別の音、`LightningImpactFx`）、サンダーホップに配線されていること。
- PlayMode `LightningVfxPlayModeTests`：初撃は一度に全体が出て約 0.1 秒で消え、枝が多い。連鎖の横アークは先端が走ってから全体が出て、白芯と縁が別設定。命中の残留アークは品質ごとの本数で 0.2 秒以内に消え、床リングは中以上。
- PlayMode `DischargeFxPlayModeTests`（放電の実物：`HitscanWeapon`＋`WeaponFx`＋`HitFlash` 付きの的）：①初撃の敵は放電のフレームで爆ぜて（床リングは床の高さ、破裂音が鳴る）強さ 0.5 で光り、連鎖先のダメージもそのフレームで確定しているが、連鎖先の爆発と白い明滅は横アークの開始前には出ず、到達で出る（電気音も）。②連鎖先が放電のフレームで消えても、最後の位置で二発目が出る（例外なし）。③2 人が同じフレームで放電すると、初撃も二発目もちょうど 2 つずつ（二重再生なし）で、2 人ともカメラが揺れる。④1 人だけ放電すると、そのプレイヤーのカメラだけ揺れる。⑤空中の連鎖先には床リングが出ない。
- Editor（Play、雷ウサギで 2 体の的を撃ち、雷撃の 2・8 フレーム後に一時停止して撮影）：高・中・低と 9 m・3 m を確認（`Screenshots/Lightning/`、Git 対象外）。真上からのメインボルトと枝、白いコアとシアンの発光、命中の星形フラッシュ・衝撃リング・火花・残留アーク、連鎖先への細い雷と小さい命中が出ること、3 m でも光輪が画面の 2 割に収まること、低では枝とリングが消えること。
- 性能：Editor 上の表示は 87〜88 FPS で雷撃前と変わらなかった（Editor の値は参考）。ビルドでの Ally X 計測はまだ。
- Editor だけの見え方：雷撃の最初の 1 フレームだけ、ボルトや命中が無地のシアンの帯・四角になることがある（三人称の肩越しで確認）。これは Editor の非同期シェーダーコンパイル（`EditorSettings` の Asynchronous Shader Compilation、このプロジェクトは有効）が、新しいシェーダーの組み合わせをコンパイルする間に出す仮のシアン表示で、雷の不具合ではない。ビルドではシェーダーが事前にコンパイル済みなので出ない（初回の小さな引っかかりの可能性はある）。撮影で避けたいときは一度雷を出してから撮る。
- 確認用の動画：PlayMode `LightningCaptureTests`（`[Explicit]`、`--include-explicit` で実行）が `Screenshots/Lightning/` に 1280×720・30 fps の MP4 を書き出す。区間は 一人称（高）で雷撃 2 回 → 横から 1/4 スロー → 命中の寄り 1/4 スロー → 一人称（中＝Ally X 既定）。スローは放電の 1 発前から録る。3 コマごとの静止画（`*_frames/`）も出す。`Capture_GlowBoost` は外側の発光を強めた比較版（色 1.7 倍・広がり 1.4 倍）で、撮影後にマテリアルを元に戻す。
  - 2026-11-08 の比較：発光を強めても明るい空と床の上では白く飛ぶだけでシアンは濃くならず、命中の白い光が敵を覆う範囲が広がった。一人称 9 m では雷撃が小さく（高さ 3.4 m）、約 0.2 秒で消えるので目立たない。発光の量より、色の濃さ（明るい背景で白に飛ばないこと）と一人称での大きさ・長さが課題だった。

  - 修正前 `Lightning_Accept_Before.mp4`・修正後 `Lightning_Accept_After.mp4`・左右に並べた `Lightning_Accept_Compare.mp4`（等速）。※修正前は直後に録っていたので、粒子が 1 フレーム遅れて写っている。
